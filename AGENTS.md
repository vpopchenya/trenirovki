# Карманный тренер — каталог упражнений (PWA)

Бесплатное приложение для зала: 7 групп мышц со схемой тела, у каждого упражнения техника по шагам на русском,
частые ошибки и ролик. Потом — готовые программы, дневник подходов, свои программы. Работает без интернета,
ставится на телефон с сайта. Рабочее название, может поменяться.

Общие правила студии — в `~/.codex/AGENTS.md` (источник — репозиторий `studio`). Где правила проекта
расходятся с общими, главнее эти.

## Где что лежит
- Бриф, техтребования, мудборд и макет — в **приватном** `studio`: `docs/requirements/trenirovki/`,
  `docs/design/trenirovki/` (там деньги и планы, сюда не переносим).
- Карточки — доска «Студия», задачи этого репозитория. Этап 1 — vpopchenya/trenirovki#1.

## Правила проекта (не нарушать)
- **Репозиторий публичный.** Только код и тексты упражнений. Никаких цен, планов заработка, личных данных,
  токенов. Перед коммитом — `git status` и глазами по добавляемым файлам.
- **Сначала телефон.** Вёрстка от 375, потом 768, 1280, 1920. До 1024 — нижнее меню, с 1024 — верхнее.
- **Дизайн «Блины»** (утверждён 28.10.2026): графит `#121417`, действие — оранжевый `#FF7A1A`, у каждой группы
  мышц цвет соревновательного блина (`--g-*` в `src/styles/global.css`): грудь красная, спина синяя, плечи
  жёлтые, ноги зелёные, руки белые, ягодицы оранжевые, пресс сиреневый (серый сливался с белыми руками).
  Шрифты Unbounded 800 (заголовки) / Nunito
  (текст) / IBM Plex Mono — локально через `@fontsource` (без Google Fonts: приложение должно работать офлайн).
- **Данные отдельно от кода.** Группы — `src/data/groups.json`, упражнения (шаг 2) — отдельные файлы в
  `src/content/`. Одно место для одной вещи.
- **Схема тела** — `src/data/body.json` из `react-native-body-highlighter` (MIT, текст —
  `src/data/body.LICENSE.txt`). Автора указываем на странице «О проекте» — не убирать.
- **Чужие ролики** — только встроенный плеер YouTube по нажатию, не скачиваем и не перезаливаем.
- **Не выдумываем:** нет данных — заглушка с пометкой `ЗАГЛУШКА`. Тексты техники вычитывает Вадим.
- **Предупреждение о здоровье** на страницах упражнений, программ и статей: «Приложение не заменяет врача…» (текст смягчён 30.10.2026, `HEALTH_WARNING`).

## Процесс (решение Вадима 28.10.2026)
Пока продукт не готов — **лёгкий процесс, чтобы правки после «да» быстро доезжали до прода**:
- ревью изменений — как обычно (`/check`, ревьюер);
- проверка — сборка без ошибок и скриншоты на 375 / 768 / 1280; тяжёлых автотестов и проверок в CI нет;
- автотесты (pytest + Playwright) в CI подключаем, когда продукт будет готов (решение Вадима 31.10.2026 отменило
  «автотесты дневника останавливают выкладку»). Пока `tests/` — только проверки дневника, запускаем руками;
- выкладка: коммит в `main` → push → GitHub Actions сам собирает и выкладывает на GitHub Pages.

## Команды
- `npm install` — поставить зависимости (Node 22).
- `npm run dev` — разработка, http://localhost:4321/trenirovki/
- `npm run build` — сборка в `dist/`.
- `.venv\Scripts\python -m pytest` — проверки дневника, идут по `dist/`: сначала сборка. Первый раз:
  `python -m venv .venv`, `.venv\Scripts\pip install -r tests/requirements.txt`, `.venv\Scripts\playwright install chromium`.

## Стек
Astro 7 (статичные страницы), TypeScript в `<script>` компонентов, GitHub Pages
(`https://vpopchenya.github.io/trenirovki/`). Работа без интернета (Workbox) и установка на телефон — шаг 4.

В записи и в файле поле `rest` {`endsAt`, `total`, `from`, `to`}: `from` — упражнение сделанного подхода, `to` — куда идём, положение сразу стоит на `to`; после последнего подхода тренировки отдыха нет, при завершении поле очищается. Считаем по часам (`endsAt`), а не тиками. Длительность — верхняя граница записи программы, «1,5–2 мин» → 2:00, непонятная запись роняет сборку (`restSeconds`). `peek` — с отдыха открыли упражнение (исправить подход, техника), таймер идёт, вверху пилюля; в peek «Готово» по макету пишет новый подход. Сигнал (звук + вибрация) один раз; истёкший, пока не смотрели (свернули, ушли, обновили), — без сигнала, время показываем честно. Звук разрешается нажатием: «Готово», «Продолжить», ±15. Выбор звука пишется в базу до перерисовки. Экран не гаснет на экранах тренировки (Wake Lock, при возврате просим заново), нет поддержки — подсказка на отдыхе. «Пропустить» и «Сохранить» тоже гасят кнопку на 450 мс: на их месте появляется другая главная кнопка. На телефоне звук, вибрация и Wake Lock ещё не проверены.
